# 🛒 E-Store 

A modern and responsive e-commerce web application built with Next.js, designed for showcasing products with a clean UI, smooth navigation, and scalable architecture.

---

## 🚀 Project Overview

This project is a **frontend e-commerce store** where users can browse different product categories, view product listings, and experience a modern shopping UI.

It focuses on:

* Clean UI/UX design
* Fast performance (Next.js SSR/SSG)
* Responsive layout for all devices

---

## 🧰 Tech Stack

* Next.js (React Framework)
* Tailwind CSS (Styling)
* React Icons (UI Icons)
* Static / JSON-based product data

---

## 🎯 Features

### 🏠 Home Page

* Hero section with banner
* Featured categories (cameras, watches, mobiles, etc.)
* Modern responsive layout

---

### 🛍️ Product Listing

* Grid-based product display
* Category-based browsing
* Clean product cards with image, title, and price

---

### 📱 Responsive Design

* Mobile-first UI
* Fully responsive across:

  * Mobile 📱
  * Tablet 📟
  * Desktop 💻

---

## 🎨 UI/UX Design

* Minimal and modern design approach
* Tailwind CSS utility-first styling
* Consistent spacing and typography
* Smooth layout alignment using flex & grid
